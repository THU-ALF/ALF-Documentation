# ALF Interactivity Tools

The ALF tools help you build interactive XR lessons in Unity: scenes to stand in, step-by-step instructions, buttons learners can press, machines that come apart, parts that move, and more.

You don't need to be a Unity expert. New to Unity? Read [Before you start](./before-you-start.md) first. Each tool then has short step-by-step guides. The first guide of each tool, linked under **Start here** below, covers what you need and the main choice to make.

## Building a lesson, in order

1. **Create the scene** with [Scene Generation](./tools/scene-generation/index.md).
2. **Add what the learner works with:** models with [Object Spawner](./tools/object-spawner/index.md) (prepared with the [Model Adjuster](./tools/model-adjuster/index.md) if needed), buttons with [Button Injection](./tools/button-injection/index.md), moving parts with the [Kinematic Editor Tool](./tools/xr-kinematics/index.md), machines that come apart with [Exploded View](./tools/exploded-view/index.md), and so on.
3. **Add content to read and watch:** charts with [Graphs](./tools/graphs/index.md), code with the [Syntax Highlighter](./tools/syntax-highlighter/index.md), videos with the [YouTube Player](./tools/youtube-player/index.md), and recorded demonstrations with [Motion](./tools/motion/index.md).
4. **For AR on a real object,** line it up with [Positioning Setup](./tools/positioning/index.md).
5. **Build the lesson steps** with [Scenario Setup](./tools/scenario-setup/index.md), which ties everything together.
   Then add a warm-up with [XR Pre-Training](./tools/xr-pre-training/index.md), so learners practise the controls first.
6. **Add the lesson to the start menu** with [Main Menu Setup](./tools/main-menu/index.md).

## Where to find the tools

In Unity's top menu, under **ALF**. The tools that add things to a scene are under **ALF > Interactivity**.

## The tool windows work in similar ways

- **Many tools have a list on the left** of what you've already made in the scene. Click an item to change it.
- **On the right are numbered steps,** one at a time. Work through them in order with **Next**.
- **The heading above the steps** tells you whether you're editing something that exists, or setting up something new.
- **When you're done,** save the scene with **Ctrl+S**.
- **Stop Play mode before using a tool.** Changes made while the scene is playing are lost.

:::tip[New to Unity?]
The Unity words used in these guides (Scene, Hierarchy, Inspector, Play mode) are explained in [Before you start](./before-you-start.md).
:::
