# Tools

The ALF tools, in the order you would usually use them to build a lesson. In Unity, you find them all in the top menu under **ALF**. The interaction tools are under **ALF > Interactivity**, the content tools under **ALF > Content Creation**, and the checks under **ALF > Utils**.

| Tool | What it does |
|---|---|
| [Scene Generation](./scene-generation/index.md) | Creates a new lesson scene, in VR or AR, with the player set up. |
| [Main Menu Setup](./main-menu/index.md) | Builds the start menu, with one button per lesson. |
| [Scenario Setup](./scenario-setup/index.md) | Builds the lesson as a series of steps, with instructions, changes in the room, and ways to finish each step. |
| [XR Pre-Training](./xr-pre-training/index.md) | Adds a short warm-up before a lesson, so learners practise the XR controls first. |
| [Guidance Setup](./guidance-setup/index.md) | A simpler version of Scenario Setup: instruction panels only. |
| [Button Injection](./button-injection/index.md) | Adds pressable buttons to a machine, or anywhere in the room. |
| [Model Adjuster](./model-adjuster/index.md) | Turns, resizes and sets a model on the ground before you place it. |
| [Object Spawner](./object-spawner/index.md) | Puts a model into the scene, and decides whether learners can pick it up. |
| [Exploded View](./exploded-view/index.md) | Pulls a machine apart into its pieces, and puts it back together. |
| [Kinematic Editor Tool](./xr-kinematics/index.md) | Makes parts slide, swing or spin, with buttons to control them. |
| [Part Palette](./part-palette/index.md) | A board on the wall with small models of parts. Poking one gives the learner the real part. |
| [YouTube Player](./youtube-player/index.md) | Adds a video screen that stays in the room. |
| [Graphs](./graphs/index.md) | Turns a CSV file or formulas into a chart that stands in the room. |
| [Syntax Highlighter](./syntax-highlighter/index.md) | Shows program code on a board, coloured like in a code editor. |
| [Motion](./motion/index.md) | Records how you operate a machine and replays it as ghost hands with your voice. |
| [Planetary Lab](./planetary-lab/index.md) | A falling-objects experiment with gravity and air resistance on Earth, the Moon or Mars. |
| [Positioning Setup](./positioning/index.md) | AR only: lines up a 3D model with a real object using printed QR codes. |
| [Utilities](./utilities/index.md) | Scene Check and Project Status: find stray cameras and check the project settings. |
