# Choose the chart

**Goal:** pick the kind of chart and what it shows, in step **2 Chart**.

A new graph starts with settings the tool chose from your data. Change anything here.

## Kind of chart

| Kind | Good for |
|---|---|
| **Bar chart** | Comparing values between categories, such as results per group. |
| **Line chart** | Values that change over time or along a measurement. |
| **Scatter plot** | Pairs of measurements, to show a relationship. |
| **Box plot** | How values are spread: median, quartiles and outliers, per column or per group. |
| **Histogram** | How often values fall into ranges (bins). |

## What it shows

- **Horizontal axis**: the column along the bottom. Choose **Row number (1, 2, 3, …)** if there's no suitable column.
- **Columns to draw**: tick the columns to show, up to 8. Each gets its own colour, which you can change.
- **Title**, **Horizontal axis title**, **Vertical axis title**: leave a field empty for none. **Fill in the axis titles from the column names** fills them in for you.

## Box plots

- **Columns with the raw values**: one box per column.
- **Split into groups by**: one box per group, for example per class.
- If your table already holds the finished values (minimum, quartiles, median, maximum), choose **Columns with the finished values** and say which column holds which.

How the quartiles are calculated, the whiskers and the mean are set in [step 3](./change-the-look.md#box-plots-and-histograms).

## Histograms

Tick the **columns with the raw values**. All columns share the same bins. Bin width and counts or percentages are set in [step 3](./change-the-look.md#box-plots-and-histograms).
