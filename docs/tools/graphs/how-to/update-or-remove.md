# Update or remove a graph

## Use new values from the same file

1. Change and save the file in your spreadsheet program.
2. Click the graph in the list.
3. In step **1 Data**, press **Read the file again**.

Every graph using that data is updated. Undo with **Ctrl+Z** if needed.

## Use another file or formulas

Click the graph, then in step **1 Data** choose **Use another file…** or **Use formulas instead…**. To change the formulas of a formula graph, press **Change the formulas…**.

If no other graph uses the old data any more, the tool asks whether to move it to the recycle bin.

## Remove a graph

1. Click the graph in the list.
2. In step **5 Save**, press **Remove this graph from the scene**.
3. Choose:
   - **Remove with its data**: also moves the data to the recycle bin, if no other graph uses it. **Ctrl+Z** doesn't bring the data back.
   - **Remove, keep the data**: keeps the data in the project, to use again later.

## Good to know

- **A file already in the project is never deleted**, only copies the tool made.
