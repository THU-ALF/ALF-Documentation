# Change the look

**Goal:** set the size, colours and extras of a graph, in step **3 Appearance**.

## Size and text

| Setting | What it does |
|---|---|
| **Width (m)**, **Height (m)** | Size of the board. |
| **Text size (cm)** | Size of all labels. |
| **Number style** | How numbers on the axes are written. |
| **Logarithmic horizontal axis** / **Logarithmic vertical axis** | For values that span several powers of ten. |
| **Fit vertical axis to the data** | Untick to set the lower and upper end of the vertical axis yourself. |
| **Grid lines** | Lines behind the chart to help read values. |

## Theme and board

| Setting | What it does |
|---|---|
| **Theme** | **Light**, **Dark**, **High contrast**, **Blackboard (green)** or **Glass for AR (see-through)**. |
| **Board colour** | Any colour. Texts switch to black or white when needed, so they stay readable. **Back to the theme's board** undoes it. |
| **Board opacity (%)** | From solid to invisible. Below 25 %, check the texts on the headset. |

## Lines and points

For line charts and scatter plots:

- **Mark data points** draws a symbol at each value.
- For every column: the **Line** (**Solid**, **Dashed**, **Dotted**, **Dash and dot**), how it connects the points (**Straight from point to point** or one of the **Steps**), and the **Point shape** (circle, square, diamond, triangles, cross, plus, star).

Giving each column its own line and shape helps learners who can't tell colours apart.

## Values, trend lines and reference lines

| Setting | What it does |
|---|---|
| **Write the values** | Writes the value next to every bar or point, while there are 60 or fewer. |
| **Trend line** | **Straight line (y = m·x + b)**, **Straight line through zero (y = m·x)** or **Exponential curve (y = a·e^(k·x))**, fitted to each column. Its equation and R² are shown under the legend. |
| **Reference lines and bands** | Up to eight lines or bands with a label, such as a pass mark or a tolerance range. Press **+ Add a reference line** and choose **Horizontal line**, **Vertical line**, **Horizontal band** or **Vertical band**. |

## Box plots and histograms

- **Box plots:** choose how quartiles are calculated, as your textbook or calculator does it. A note under the chart names the method, so learners can compare. Also choose the whiskers and whether the mean is shown.
- **Histograms:** **Choose the bin width automatically**, or set a **Bin width**. Tick **Shares in percent** to show percentages instead of counts.
