# Scene Generation

**Menu:** ALF > Scene Generation

Creates a new, empty lesson scene with everything a learner needs to stand in it: the **player setup** (headset, controllers or hands) and, if you like, a **VR room** or a **floor**. It can also switch the player setup of a scene you already have, for example from controllers to hands.

This is usually the first tool you use for a new lesson.

## Quick start

1. Open **ALF > Scene Generation**.
2. Choose **Create New Scene** and type a **New Scene Name**.
3. Choose the **Target XR Mode**: VR or AR, with controllers or hands.
4. For VR, tick **Include VR Room** if you want a ready-made room.
5. Press **Create & Setup New Scene**.

The new scene is saved in `Assets/ALF-Generated/Scenes` and opened, ready for you to add content.
