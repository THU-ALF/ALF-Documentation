# Add a button that opens the model

**Goal:** give learners a physical push button that opens the model and closes it again.

## Steps

1. Select the exploded view in the list on the left.
2. Open step **5 Trigger** and choose **a push button**.
3. The button's position is already proposed: on the surface the model stands on, 15 cm to the side of the model. You can see the numbers in the position fields.
4. To move it, type a new position, or use *Place visually*.
5. In step **6 Save**, press **Save into the scene**. The button is created now. Then save the scene with **Ctrl+S**.

## Result

A push button stands beside the model. Each press opens the model if it's closed, and closes it if it's open.

## Put the button back beside the model

Once you type your own position, the tool stops suggesting one. To go back to the suggested spot, press **Put it beside the model**. This also moves the button if it already exists.

## Good to know

- **The button doesn't come apart with the model.** It's marked as a control, so it always stays where you put it.
- **The button's look is fixed.** It always uses the standard ALF push button.
- **Want a reset button too?** That's set up in step 4. See [Let learners pick up the pieces](./let-learners-handle-pieces.md#add-a-reset-button).
