# Utilities

**Menu:** ALF > Utils

Two small tools that check your scene and project for problems:

| Tool | What it does |
|---|---|
| [Scene Check](./scene-check.md) | Finds extra cameras, often hidden inside imported models, that spoil what learners see in the headset. |
| [Project Status](./project-status.md) | Checks that the project is set up for QR code tracking, used by [Positioning Setup](../positioning/index.md), and fixes what it can. |
