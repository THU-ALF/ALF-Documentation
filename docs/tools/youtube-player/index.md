# YouTube Player

**Menu:** ALF > Content Creation > YouTube Player Setup

Adds a **video screen** that plays a YouTube video and stays in the room for the whole lesson, for example an introduction video by the entrance, or a how-to video next to a machine. Learners start and pause it with its own controls.

:::tip[Video for one lesson step?]
For a video that belongs to one step of a lesson, use the video option in [Scenario Setup](../scenario-setup/how-to/write-the-instructions.md#video) or Guidance Setup instead. This tool is for a screen that's always there.
:::

## Quick start

1. Open **ALF > Content Creation > YouTube Player Setup**.
2. Paste the link into **YouTube URL**, and check that **Video ID detected** appears.
3. Set the **Spawn Coordinates** and **Player Size**.
4. Press **Generate YouTube Player**.
5. Save the scene with **Ctrl+S**.
