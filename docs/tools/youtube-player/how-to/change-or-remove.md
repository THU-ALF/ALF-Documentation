# Change or remove a video screen

The tool only creates screens. To change one afterwards, work with it directly in the scene.

## Move a screen

1. Click the screen in the Hierarchy or the Scene view.
2. Move it with the move tool in the Scene view, or type its **Position** in the Inspector.
3. Save the scene with **Ctrl+S**.

## Show a different video

The simplest way is to replace the screen:

1. Note where the old screen stands. Its **Position** is shown in the Inspector.
2. Delete the old screen: select it in the Hierarchy and press **Delete**.
3. [Add a video screen](./add-a-video-screen.md) with the new link, at the same **Spawn Coordinates**.
4. Save the scene with **Ctrl+S**.

## Remove a screen

1. Select the screen in the Hierarchy.
2. Press **Delete**.
3. Save the scene with **Ctrl+S**.
