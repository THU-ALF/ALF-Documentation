# Part Palette

**Menu:** ALF > Interactivity > Part Palette

A board on the wall with small 3D models of parts, like the drawers of an electronics bench: one column per kind of part, one row per variant. When a learner pokes a cell, the real part appears in front of the board, ready to grab.

## Quick start

1. Open **ALF > Interactivity > Part Palette**.
2. **1 Configuration:** choose the configuration asset.
3. **2 Layout:** add columns, and put a part in each row.
4. **3 Appearance:** adjust the look if you like.
5. **4 Spawned Parts:** choose what learners can do with a part.
6. **5 Scene:** press **Add to Scene**, then move the board into place.
7. Save the scene with **Ctrl+S**.

:::note[The board looks empty in the editor]
The board is built when the lesson starts. To see it while you work, use the preview. See [How the palette is built](./how-to/before-you-start.md#two-things-to-know-about-this-tool).
:::
