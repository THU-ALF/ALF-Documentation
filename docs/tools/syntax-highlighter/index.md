# Syntax Highlighter

**Menu:** ALF > Content Creation > Syntax Highlighter

Puts **program code** on a board in the room, coloured like in a code editor and readable in VR and AR. Keywords, types, methods, strings, numbers and comments each get their own colour, with line numbers and an optional title bar. It colours **C#**, **Java**, **C** and **Python**.

Learners scroll through longer code with the controller's thumbstick, by dragging, or with a fingertip.

## Quick start

1. Open **ALF > Content Creation > Syntax Highlighter**.
2. In step **1 Code**, choose the **Language**, type a **Title**, and paste the code or press **Choose a file…**.
3. Press **Add the code board to the scene**.
4. In step **2 Appearance**, choose the colours and size.
5. In step **3 Placement**, set where the board stands.
6. In step **4 Save**, press **Save the scene**.
