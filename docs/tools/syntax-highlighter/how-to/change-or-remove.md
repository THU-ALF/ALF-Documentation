# Change or remove a code board

## Change the code

1. Click the board in the list. The steps are headed **Editing '…'**.
2. In step **1 Code**, edit the code, or press **Choose a file…** to load a new version of the file.

The board is updated straight away.

## Rename

Changing the **Title** also renames the board to `Code - ` followed by the new title, unless you renamed the board yourself.

## Remove

1. Click the board in the list.
2. In step **4 Save**, press **Remove this code board from the scene** and confirm.

**Ctrl+Z** brings it back.
