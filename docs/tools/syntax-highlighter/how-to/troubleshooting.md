# Troubleshooting

## "No code to show"

The code field is empty. Type, paste or load some code first.

## The end of my code is missing

A board shows up to about 10,000 characters. The tool warns you when code is cut off. Split it over several boards, or under **Leave out** remove comments and empty lines.

## The file couldn't be read

Files must be 128 KB or smaller. Check that the file isn't open and locked in another program, and choose it again.

## Some characters show as boxes

The board's font can't show them, for example emoji or some symbols. The tool lists them under the code. Replace them in the code, for example in comments.

## A name isn't coloured as a type

Add it under **Also colour as types** in step 2.

## Columns don't line up

Tick **Even letter widths** in step 2.

## Learners can't scroll

Check that the scene has an Event System that works with XR. Scenes made with [Scene Generation](../../scene-generation/index.md) have one. With a controller, point at the code and use the thumbstick, or drag.

## My change to the file doesn't show

The board holds a copy of the code. Load the file again with **Choose a file…**.
