# Place the board

**Goal:** set where the code board stands, in step **3 Placement**.

## Steps

1. Select the board in the list.
2. In step **3 Placement**, choose where it stands:
   - **in the world**: it stays where you put it;
   - **on an object**: it moves along with that object.
3. Set the **position** and **rotation**. Move it in the Scene view if that's easier.
4. Save the scene in step **4 Save**.

The board is read from its front. Make sure it faces where learners will stand.

## How learners scroll

When the code is longer or wider than the board, scrollbars appear along the right edge or the bottom. Learners can scroll:

- with the **thumbstick** while the controller points at the code,
- by **dragging** the code or a scrollbar with the controller ray or a pinch,
- by **touching** the code or a scrollbar with a fingertip and dragging.

The scrollbars are wide enough to hit with a finger.

## Good to know

- **The scene needs an Event System** for scrolling to work, as for other XR menus. Scenes made with [Scene Generation](../../scene-generation/index.md) have one.
- **A nearly invisible board doesn't block** what's behind it. Below 5 % opacity, only the code itself reacts to pointing.
