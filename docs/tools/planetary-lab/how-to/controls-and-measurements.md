# Set what learners can change and measure

## What learners can change (step 4 Controls)

Set the lowest and highest value learners can choose, and the value their **Default** button returns to:

| Control | Learners change… | Up to |
|---|---|---|
| **Gravity (m/s²)** | how strongly the objects are pulled down | 25 m/s² by default (Earth: 9.81) |
| **Density (kg/m³)** | how thick the air is | 5 kg/m³ by default (Earth: about 1.2) |
| **Left mass (kg)** | the mass of the left object | 0.005 to 10 kg by default |

The ranges must include every environment in **Selectable presets**, and the starting mass of the left object.

When learners pick an environment, gravity and air density jump to its values. When they set values themselves, the conditions are shown as **Custom**. Resetting a drop keeps the learners' settings.

## What is measured (step 5 Measurements)

| Setting | What it does |
|---|---|
| **Maximum run time (s)** | A drop stops after this time and shows its graphs, even if an object hasn't landed, for example a feather on the Moon with air. |
| **Guided drop completion** | When a drop counts as finished for the guided lesson, for example only after both objects have landed. |

Below these are the graphs each object's **height** and **speed** are drawn into. They're set up for you; change them only if you've replaced the graphs.

## Good to know

- **The graphs are redrawn after each drop**, not during it.
- **The force arrows** show weight, air resistance and buoyancy. After landing, they show the forces just before impact.
