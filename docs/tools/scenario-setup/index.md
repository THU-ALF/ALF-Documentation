# Scenario Setup

**Menu:** ALF > Scenario Setup Tool

Builds the lesson itself: a sequence of **steps** the learner works through. For each step you decide:

- **what the learner reads or watches**: an instruction panel with text, an image or a YouTube video;
- **what changes in the room**: objects that appear or disappear;
- **how the step finishes**: for example, pressing *Next*, walking to a place, or pressing a button.

This is the tool that connects the others. Buttons from [Button Injection](../button-injection/index.md), models from [Object Spawner](../object-spawner/index.md) and machines from [Exploded View](../exploded-view/index.md) all come together here.

## Quick start

1. Place what the lesson needs first: objects, machines and buttons.
2. Open **ALF > Scenario Setup Tool**.
3. **1 System:** set the **Number of Steps** and press **Update Count**.
4. **2 Steps:** click each step in the list and fill in both halves:
   - **Environment & Flow:** what changes in the room, and how the step finishes;
   - **Guidance & UI:** the instruction panel.
5. **3 Generate:** check that no problems are listed, then press **Spawn New Scenario System**.
6. Save the scene with **Ctrl+S**.
