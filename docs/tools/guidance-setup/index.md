# Guidance Setup

**Menu:** ALF > Guidance Setup Tool

Builds a series of **instruction panels** that the learner works through with **Next** and **Previous**. Each panel shows text, an image or a YouTube video.

It's the simpler sibling of [Scenario Setup](../scenario-setup/index.md): it has the same instruction panels, but steps can't change the room or wait for a button. If you need either of those, use Scenario Setup instead.

## Quick start

1. Open **ALF > Guidance Setup Tool**.
2. **1 System:** set the **Number of Steps** and press **Update Count**.
3. **2 Steps:** click each step in the list, and fill in its content and placement.
4. **3 Generate:** check that no warnings are listed, then press **Spawn New Guidance System**.
5. Save the scene with **Ctrl+S**.
