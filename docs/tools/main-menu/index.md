# Main Menu Setup

**Menu:** ALF > Main Menu Setup

Builds the **start menu** of your app: a scene with a panel that has one button per lesson. When a learner presses a button, that lesson opens with the right player setup.

## Quick start

1. Make your lesson scenes first, with [Scene Generation](../scene-generation/index.md).
2. Open **ALF > Main Menu Setup**.
3. Choose the **Menu Rig Mode** and type a **Custom Title**.
4. Press **Add Scene** for each lesson, and drag the lesson's scene file from the Project window into the new row.
5. Put the lessons in order with **▲** and **▼**.
6. Press **Generate New Main Menu Scene**.
