# Before you start

You don't need to know Unity well to use the ALF tools. This page covers the few Unity terms the guides use. Each tool's first guide also lists what that tool needs.

## Unity terms you'll see

| Term | What it is |
|---|---|
| **Scene** | The 3D room your lesson takes place in. Each lesson is its own scene file. |
| **Hierarchy** | The panel listing every object in the scene, usually on the left of the Unity editor. You'll often drag objects from here into a tool. |
| **Scene view** | The large 3D view of the room, where you can look around and click on objects. |
| **Project window** | The panel listing the files in your project: scenes, models, prefabs and images. Usually at the bottom of the editor. |
| **Inspector** | The panel showing the settings of whatever is selected. The ALF tools mean you rarely need it. |
| **Play mode** | Pressing **Play** at the top of the editor runs the lesson so you can try it. Changes made while playing are thrown away when you stop. |
| **Save the scene** | Keeps your changes. Until you save with **Ctrl+S**, they exist only in the open editor. |

:::caution[Stop Play mode before using a tool]
Anything you change while the scene is playing is lost when you stop.
:::
