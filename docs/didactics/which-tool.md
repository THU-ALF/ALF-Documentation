# Which tool for which teaching goal

The tool pages start from the tool. This page starts from **what you want learners to do**.

| I want learners to… | Use | Guide |
|---|---|---|
| **see the whole task or system first** | Exploded View, opening at the first step | [Open the model at a lesson step](../tools/exploded-view/how-to/open-at-a-lesson-step.md) |
| | A video on the first panel | [Write the instructions: Video](../tools/scenario-setup/how-to/write-the-instructions.md#video) |
| **watch an expert do it, on the machine itself** | Motion: ghost hands with your voice | [Record a demonstration](../tools/motion/how-to/record-a-demonstration.md), [Create the playback for learners](../tools/motion/how-to/create-the-playback.md) |
| **watch an expert do it, on video** | A video on a panel, or a video screen in the room | [Write the instructions: Video](../tools/scenario-setup/how-to/write-the-instructions.md#video), [Add a video screen](../tools/youtube-player/how-to/add-a-video-screen.md) |
| **follow steps one at a time** | Scenario Setup | [Create a scenario](../tools/scenario-setup/how-to/create-a-scenario.md) |
| | Guidance Setup, if steps only show panels | [Create a guidance sequence](../tools/guidance-setup/how-to/create-a-guidance-sequence.md) |
| **read help right next to the part** | Panels placed at or on the object | [Place the instruction panel](../tools/scenario-setup/how-to/place-the-instructions.md) |
| | Labels | [Add a label](../tools/button-injection/how-to/add-a-label.md) |
| **get help on the real object** | AR with Positioning Setup | [Positioning Setup: How QR alignment works](../tools/positioning/how-to/before-you-start.md) |
| **do the action, not click Next** | A step that finishes on a button or a place | [Choose how a step finishes](../tools/scenario-setup/how-to/choose-how-a-step-finishes.md) |
| **press, switch or operate controls** | Button Injection | [Add a button to an object](../tools/button-injection/how-to/add-button-to-object.md) |
| **find and press the right part of a machine** | A clickable part | [Make a part of a machine clickable](../tools/button-injection/how-to/make-a-part-clickable.md) |
| **see parts move and react** | Kinematic Editor Tool | [Add buttons that move the parts](../tools/xr-kinematics/how-to/connect-to-a-button.md) |
| **hear or see that something happened** | Sound or light on movement | [Play a sound or effect when a part moves](../tools/xr-kinematics/how-to/react-to-movement.md) |
| **see inside a machine** | Exploded View | [Make a model come apart](../tools/exploded-view/how-to/make-a-model-come-apart.md) |
| **focus on one part of a machine** | Exploded View of a part | [Explode part of a machine](../tools/exploded-view/how-to/explode-part-of-a-machine.md) |
| **turn parts in their hands** | Exploded View with handling, or Object Spawner | [Let learners pick up the pieces](../tools/exploded-view/how-to/let-learners-handle-pieces.md), [Choose what learners can do with an object](../tools/object-spawner/how-to/choose-what-learners-can-do.md) |
| **choose the right part from similar ones** | Part Palette | [Create a palette](../tools/part-palette/how-to/create-a-palette.md) |
| **read data and connect it to what they see** | Graphs | [Graphs](../tools/graphs/index.md) |
| **experiment with conditions and see the effect** | Planetary Lab, a ready-made experiment | [Planetary Lab](../tools/planetary-lab/index.md) |
| **read program code in the room** | Syntax Highlighter | [Syntax Highlighter](../tools/syntax-highlighter/index.md) |
| **compare right and wrong** | Image panel, or two objects side by side | [Write the instructions: Image](../tools/scenario-setup/how-to/write-the-instructions.md#image), [Place an object](../tools/object-spawner/how-to/place-an-object.md) |
| **only see what the step needs** | Show or hide objects per step | [Show or hide objects during a step](../tools/scenario-setup/how-to/show-or-hide-objects.md) |
| **go to the right place** | A step that finishes when a place is reached | [Choose how a step finishes](../tools/scenario-setup/how-to/choose-how-a-step-finishes.md#reach-a-place-in-the-room) |
| **practise the controls first** | A practice scene, first in the menu | [Create a lesson scene](../tools/scene-generation/how-to/create-a-lesson-scene.md), [Create the main menu](../tools/main-menu/how-to/create-the-main-menu.md) |
| **use their hands like in reality** | A hands player setup | [Scene Generation: The five player setups](../tools/scene-generation/how-to/before-you-start.md#the-five-player-setups) |
| **go through stages or levels in order** | One scene per stage or level, in the main menu | [Create the main menu](../tools/main-menu/how-to/create-the-main-menu.md) |

## Not possible yet

| I want learners to… | Workaround for now |
|---|---|
| get a message when they do something wrong | Name the typical mistake on the step; supervisor and debrief. See [Plan for mistakes](./plan-for-mistakes.md). |
| get less help automatically as they improve | Separate scenes per run or level. See [Plan the support](./plan-the-support.md). |
| type or record an answer | Aloud, in pairs or on paper. See [Close the loop](./close-the-loop.md). |
