# Checklist before learners try it

Go through this list before the first session with learners. Each item links to the guideline that explains it. Print it with your browser's print function (**Ctrl+P**).

## Goal

- [ ] The goal is one sentence with an observable action, and every step serves it. → [1.1](./start-from-the-goal.md#11-write-the-goal-as-one-observable-action)
- [ ] The final check matches the goal, and you know how it's done. → [1.2](./start-from-the-goal.md#12-decide-how-youll-check-the-goal-before-you-build)
- [ ] The lesson starts with an overview of the whole task or system. → [1.4](./start-from-the-goal.md#14-show-the-whole-before-the-parts)

## Stages

- [ ] Every stage uses the same task, order and words. → [2.2](./choose-the-stages.md#22-keep-the-same-task-in-every-stage)
- [ ] You know what XR can't teach for this task, and where learners practise it instead. → [2.4](./choose-the-stages.md#24-plan-what-xr-cant-teach)
- [ ] Help goes down from run to run, or from stage to stage. → [3.2](./plan-the-support.md#32-remove-the-help-from-the-end-first)

## Steps

- [ ] Each step asks for one action. → [4.1](./design-each-step.md#41-one-step-one-action)
- [ ] Instructions are next to what they describe. → [4.2](./design-each-step.md#42-put-the-instruction-where-the-action-is)
- [ ] Each step only shows what it needs. → [4.3](./design-each-step.md#43-show-only-what-this-step-needs)
- [ ] Learners new to XR practise the controls in a separate scene first. → [4.6](./design-each-step.md#46-teach-the-headset-before-the-subject)
- [ ] Steps with an action finish on that action, not on *Next*. → [5.1](./let-learners-act.md#51-finish-steps-with-an-action-not-with-next)

## Mistakes and ending

- [ ] The two or three typical mistakes are named at the step where they happen. → [6.2](./plan-for-mistakes.md#62-name-the-mistake-at-the-step-where-it-happens)
- [ ] Every rule comes with its reason. → [6.4](./plan-for-mistakes.md#64-give-the-reason-not-just-the-rule)
- [ ] The lesson ends with reflection, and a debrief is planned. → [7.1](./close-the-loop.md#71-end-with-a-reflection-step)

## Everyone

- [ ] Panels and controls can be reached while sitting. → [8.4](./motivation-comfort-inclusion.md#84-design-for-seated-and-one-hand-use-from-the-start)
- [ ] The same technical term is used for the same thing everywhere. → [8.5](./motivation-comfort-inclusion.md#85-make-language-easy)
- [ ] Each headset session is short, with breaks planned. → [8.3](./motivation-comfort-inclusion.md#83-keep-learners-comfortable)

## Try it

- [ ] [Scene Check](../tools/utilities/scene-check.md) shows nothing to fix.
- [ ] You went through the whole lesson yourself, in the headset.
- [ ] One learner tried it before the class, and you watched without helping.
