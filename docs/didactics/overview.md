# Plan the learning

The [tool guides](../tools/index.md) show you **how** to build a lesson. This section helps you decide **what** to build, so that learners don't just see an impressive scene, but leave able to do something they couldn't do before.

Every guideline here is based on learning research, and every one links to the ALF tool that puts it into practice. You don't need a background in teaching to use them.

## The big idea: the same task, with less and less help

ALF lessons follow one idea: learners do the **same task** several times, and each time

- the **help goes down:** fewer instructions, shorter hints;
- the **realism goes up:** from a virtual room, to digital help on the real object, to the real object alone;
- the **learner takes over** more decisions.

| Stage | Where | Help | What it's for |
|---|---|---|---|
| **Orient** | At the start | Full | See the whole task, the goal and the background. |
| **Practise in VR** | A virtual room | High, then less | Learn the task safely. Mistakes cost nothing. |
| **Transfer in AR** | The real room, with digital help on the real object | Low | Do the task on the real thing, with help where it's needed. |
| **Perform for real** | The real object, no headset | None | Show you can do it. This is where you check the goal. |

Not every lesson needs every stage. [Choose the stages](./choose-the-stages.md) helps you pick.

:::

## How each guideline is written

Each guideline has the same parts, so you can scan them quickly:

| Part | What it tells you |
|---|---|
| **Do** | What to do, in plain words. |
| **In ALF** | Which tool and guide put it into practice. |
| **The learner experiences** | What it looks like from inside the headset. |
| **Avoid** | The mistake authors often make here. |
| **Why** | The reason, and the research it comes from. |

:::note[Not built in yet]
Some guidelines need features ALF doesn't have yet, for example feedback when a learner does something wrong. Those are marked **Not built in yet**, with a workaround you can use today.
:::

## Where this fits in your work

1. **Plan** with these guidelines, on paper: the goal, the stages, the steps.
2. **Build** with the tools, in the order of [Building a lesson, in order](../intro.mdx#building-a-lesson-in-order).
3. **Check** with the [checklist](./checklist.md), then try the lesson yourself and with one learner.
